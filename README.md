# 疯狂水世界

Minecraft **1.21** / Fabric / Java **21** 的局域网钓鱼竞赛。第一个拥有 100,000 金币的玩家获胜。游戏节奏目标为约 40-60 分钟；**没有强制倒计时**，实际时长需多人测试调整。

## 安装与开发

- 客户端和局域网主机安装 Fabric API 与本模组。参与**疯狂水世界**的客户端还要安装 Minecraft 1.21 兼容的 Modern UI（其发布文件名可能标为 1.21.1）与 Forge Config API Port；只在关闭本游戏后游玩其他地图的客户端不需要界面依赖。独立服务器无需安装这两个客户端依赖。
- 用 Java 21 运行 `gradlew.bat build` 或 `gradlew.bat runClient`。生成的模组文件在 `build/libs/`（`crazywaterworld-<版本>.jar`）。
- 交易和结算界面只用原版控件，未装 Modern UI 的客户端也能打开；商店界面与 B 键仍需要 Modern UI。
- 第一次启动创建 `config/crazywaterworld.json`。`enabled` 决定**新世界**首次加载时游戏是否开启；已有世界以存档中的 `/cww on` / `/cww off` 状态为准。关闭游戏仍会注册物品、方块和菜单，旧物品不会消失。`winTarget`、`catchChance` 及四档河蚌概率可配置；四档概率总和必须为 100。

## 游戏流程

1. 屏幕左上角的 HUD 实时显示金币、目标进度条、当前名次和领先者，金币变化时会闪出 +/− 数值（F1 隐藏界面或 F3 调试时自动隐藏）。任何玩家首次达到目标的 25% / 50% / 75% / 90% 时全服播报。
   第一个玩家进入世界时自动开局；每位玩家每局首次进入时，如果背包里没有钓鱼竿，就会获得一根原版钓鱼竿（已有鱼竿则不重复发放）。`/cww start` 和 `/cww restart` 会重新检查所有在线玩家的背包，没有钓鱼竿的补发一根；`/cww start` 不会重置金币。
2. 用**任意原版钓鱼竿**在任意水域钓鱼。每次收竿只会得到一个战利品：原版鳕鱼、鲑鱼、河豚、热带鱼，或疯狂水世界的臭皮鞋、废水过滤器、海水过滤器、电鳗和河蚌；没有原版垃圾与宝藏。模组物品的占比由 `catchChance` 决定（默认 40%）；其中河蚌占模组渔获的 95%，默认无附魔时约占总渔获 38%，是单种渔获中概率最高的，海之眷顾会提高珍稀渔获概率。打捞网使用相同的模组渔获比例。按 **B** 打开商店，把渔获放到收购区（或点“全部放入”一次放入背包里所有可售渔获）并确认出售；普通鱼也有售价。相同物品卖得越多，市价最低降至基础价的 60%；无人出售时每分钟回升一档，约 20 分钟回到原价。商店“出售”分类可翻页查看全部物品的实时价格与折扣。
3. 开蚌台由地图提供，不在商店出售。商店可以买三个等级的一次性鉴定仪。主手持鉴定仪、副手持河蚌右键，查看档次或**鉴定时**市价区间。之后手持河蚌右键开蚌台，支付 500 金币开出预定奖励；开出电鳗发电机或远古海珠会全服播报。市价随后变化可能使旧区间过时。
   **河蚌不能卖给商店**，只能开蚌或与其他玩家交易。初级鉴定（200 金）用来判断是否值得花 500 金开蚌；中级（500 金）/高级（1,200 金）鉴定主要用于玩家之间给河蚌定价。
   开蚌台放置时朝向放置者，生存模式无法破坏（地图设施），创造模式可以拆除。
   工具页还出售 10,000 金币的打捞网（**每人每局限购 2 张**，防止堆网滚雪球）：只能放在与水方块水平相邻的位置，在区块加载且本局进行中时每隔 20-40 秒获得一件渔获（平均 30 秒），最多积累 27 件；右键一次取走所有库存，背包满时物品会掉在玩家附近。打捞网归放置者所有，其他玩家既不能收取也不能拆除（创造模式除外）。离水暂停，拆除会掉出库存并返还方块。不会作为开局物品发放。
   工具页可购买饵钓 I-III、海之眷顾 I-III、耐久 III 和经验修补；购买时直接升级主手鱼竿（主手不是鱼竿则检查副手），没有鱼竿或已有同级/更高级附魔不会扣金币。
4. **玩家之间只能交易河蚌。** 相距 8 格内右键另一名玩家，或使用 `/cww trade <玩家名>` 发出邀请（双方都没有河蚌时无法发起）。对方在 60 秒内点击聊天栏的 **[接受]** / **[拒绝]**（或输入 `/cww accept` / `/cww deny`）。双方各有 4 格，只能放入自己要**出售**的河蚌；金币是**要价**——自己这边设定的金额是向对方**收取**的金币（用 `±100`、`±1千`、`±1万` 调整或清零），只有放了河蚌才能要价，河蚌全部取回时要价自动归零。双方都要价时按差额结算，只有一方付钱；界面底部的“结算预览”会显示你将获得的河蚌和金币增减，余额不够支付时无法确认。每笔交易至少要包含一个河蚌，金币不能单独赠送。任何一方改变报价都会撤销双方确认，并在 2 秒内禁止再次确认，防止最后一刻换货；取消、关闭、走远或断线返还托管河蚌。
5. 第一个达到目标金币数的玩家获胜，结束本局并弹出结算页。用 `/cww results` 再次打开成绩；用 `/cww rank` 查看实时排名。

## 管理命令

- `/cww on`、`/cww off`：管理员开启/关闭本世界的疯狂水世界玩法，状态随世界保存，不用重启。切换时会重载钓鱼战利品表；关闭期间 B 键、商店、交易、钓鱼特殊掉落、河蚌鉴定/开蚌和打捞网产出均停止，已打开的商店会返还出售槽内物品，进行中的交易会退回报价。原有物品、方块、金币和河蚌奖励记录不会删除；已放置打捞网的库存仍可通过拆除取回。再开启时给背包里没有钓鱼竿的在线玩家补发一根。
- `/cww status`：查看本世界开关状态；关闭后其他 `/cww` 玩法命令不执行。
- `/cww start`：开始/继续当前回合，给背包里没有钓鱼竿的在线玩家补发一根；需要管理权限。
- `/cww restart`：重置金币、胜者、开蚌统计和市场价格，并开启新局；需要管理权限。**不会清空任何玩家背包或旧河蚌**。为保证下一局公平，请使用新世界或自行清理旧战利品。
- `/cww gold`：查看余额；`/cww sell`：出售背包内可售物品；`/cww shop`：打开商店；`/cww accept` / `/cww deny`：接受/拒绝交易邀请。

## 贴图与模型

电鳗、废水过滤器、河珠、远古海珠、三档鉴定仪（铜/银/金放大镜）、打捞网的绳网和模组图标由 `tools/draw_item_textures.js` 生成（`node tools/draw_item_textures.js`，可加一个目录参数输出 16 倍放大的预览图）。打捞网方块模型为原木框、下垂的绳网与红白浮标，绳网在 cutout 渲染层显示透空。

## 河蚌模型

河蚌物品现在使用 Blockbench 模型的 64×64 贴图和 3D 造型。成功付费开蚌后，开蚌台上会出现约 **1.5 秒**的蚌身与上盖展示，上盖沿原模型的铰链角度抬起；付费失败或无效河蚌不会播放。Minecraft 原版物品 JSON 不支持 `.bbmodel` 骨骼动画，所以动画由服务端驱动临时展示实体，附近玩家看到同一动作。客户端的背包/商店仍显示静态河蚌。

开蚌台方块和物品使用优化后的 Blockbench 模型（157 个静态部件、内嵌贴图），补充铜箍、铆钉与青绿铭牌。原模型的 `animation.bench.prying` 撬蚌动画无法由原版方块 JSON 播放；目前开蚌时仍使用上面的河蚌展示动画。修改模型后运行 `powershell -NoProfile -ExecutionPolicy Bypass -File tools/export_bbmodel_static_item.ps1 -Source "开蚌台.bbmodel路径" -ItemId clam_opener -Block` 重新导出；若改变外形边界，也要同步调整 `ClamOpenerBlock` 的点击/碰撞范围。

修改原模型几何或贴图后，可用 `powershell -NoProfile -ExecutionPolicy Bypass -File tools/export_bbmodel_item.ps1 -Source "你的河蚌.bbmodel路径" -ItemId clam` 重新导出。若修改了 `open_burst` 的关键帧，还需同步调整 `ClamOpeningAnimation` 中的时间和铰链角度；当前角度来自提供的 `.bbmodel`，帧间采用线性插值。

电鳗发电机和海水过滤器的背包/商店物品使用各自的 Blockbench 静态模型与内嵌贴图。修改原文件后运行 `powershell -NoProfile -ExecutionPolicy Bypass -File tools/export_bbmodel_static_item.ps1 -Source "模型文件.bbmodel" -ItemId eel_generator`（海水过滤器使用 `sea_filter`）。优化版本将电鳗与电弧调整为 Java 1.21 支持的单轴旋转，避免多轴旋转被包围盒替代；发电机增加电量指示，过滤器增加双压力表、滤芯包箍与出水阀。

### 五款模型的可编辑源文件

`models/refined/` 保存河蚌、开蚌台、电鳗发电机、海水过滤器和打捞网的优化版 `.bbmodel`（贴图内嵌）。河蚌的壳纹与凸起条纹随上盖一起运动；打捞网使用单层网底与四面网壁，并带有绳结、铜件和铭牌。

- 修改这些源文件后执行 `node tools/refine_models.mjs export`，重新导出全部游戏模型、贴图和河蚌动画部件，并根据几何范围重新居中、适配背包图标及调整手持比例。无需运行 Blockbench。
- `node tools/refine_models.mjs verify` 检查旋转角度、几何范围、贴图引用、图标边界及河蚌闭合时两部分的一致性。
- Blockbench MCP 开启时执行 `node tools/refine_models.mjs preview`，将**导出的 Java 模型**重新导入 Blockbench 渲染，预览位于 `build/model-previews/*-game.png`；这不是游戏内截图。
- `node tools/refine_models.mjs refine [模型ID]` 是从桌面 `模型/` 原始四份源文件重做优化的开发命令，会覆盖对应的优化版文件；普通修改后请使用 `export`。打捞网的初始结构保存在 `models/refined/salvage_net.original.json`。
- 源文件保留已有动画，但机器的原始动画仍不由原版静态物品模型播放。

## 建议的局域网验收

- 双人入服、自动发竿、重新连接不重复发竿；新世界将配置设为关闭后玩法暂停但物品仍在。
- 钓鱼仅出现四种可售原版鱼及五种模组渔获、打捞网不产出原版垃圾/宝藏；出售、价格变化/恢复、商店预估价与到账一致；存档重载后金币与市场仍在。
- 河蚌首次鉴定/再次升级、商店拒收河蚌、开蚌奖励、重复编号拒绝、旧版未标记河蚌；河蚌交易只接受河蚌、无河蚌不能确认、改价后 2 秒确认冷却。
- 打捞网仅能靠水放置、等待/存档重载后积累渔获、右键收取与拆除返还库存；商店附魔在无鱼竿、重复购买、余额不足及副手鱼竿时的行为。
- `/cww off` 后 B 键与直接输入商店命令都不能打开界面、钓鱼奖池重载后恢复原版；关闭时打开的商店退还出售槽和交易报价、打捞网暂停，重进地图仍关闭；`/cww on` 恢复原进度。
- 双人交易物品与金币、改单撤销确认、金币不足、满背包、关闭/走远/断线返还。
- 获胜只宣布一次、胜后不能继续买卖、结算排名、`/cww restart` 的新局表现。
